## 4. НАЙДЕН ПРОДУКТОВЫЙ ДЕФЕКТ (блокирующий): fit_panel_var — сущностные эффекты не идентифицируемы

**Место**: `app/modeling/panel_models.py`, строки 804–806:

```python
dummies = np.zeros((n, max(n - 1, 0)))
for index in range(1, n):
    dummies[:, index - 1] = 1.0          # ← заполняет КОЛОНКУ, а не ячейку (entity, dummy)
```

Все N−1 dummy-колонок становятся константными единицами → каждая коллинеарна
константе → дизайн [лаги, const, dummies] вырожден (SingularMatrixWarning sm.OLS —
ПРЕДУПРЕЖДЕНИЕ ВИДНО В КАЖДОМ ПРОГОНЕ, включая repo-тесты, но не интерпретировано):
(а) сущностные фиксированные эффекты фактически ОТСУТСТВУЮТ — оценка = pooled VAR
с одним эффективным интерсептом, расщеплённым pinv по 6 коллинеарным колонкам;
(б) `entity_intercepts` (возвращаются в Model Card как «эффекты сущности») — артефакты
минимально-нормального решения; (в) A-матрицы и `base_intercept` смещены на панелях
с гетерогенными уровнями (типичный панельный случай); (г) рекурсивный прогноз и
движок (fold-local фиты, по-переменные метрики) наследуют смещение.

**Доказательство** (оракул O30a-d, O32, O33, O63b + диагностика): корпус NS-VAR —
VAR(1) A=[[0.85,0.1],[−0.1,0.9]], c=(1,2), alpha_i=(i,2i), T=24, без шума.
Продукт: Â=[[0.805,0.245],[−0.190,1.191]], base≈[0.116,0.232] (ожидание [1,2]),
R2≈{0.9986, 0.9907} ≠ 1. Тот же дизайн с корректной ячейковой записью
`dummies[index, index - 1] = 1.0` (ЕДИНСТВЕННОЕ отличие): Â == A точно, base=[1,2],
dummy-коэффициенты == alpha_i−alpha_0, R2 == 1.0 ровно.

**Почему repo-тесты пропустили**: DGP `_make_var_panel` — `y_t = A·y_{t−1} + e_t`
БЕЗ сущностных эффектов (E[y]=0, однородные сущности) — вырожденность не влияет на
восстановление A в допуске 0.1; `test_var_entity_dummies_in_regressors` проверяет
только `entity_dummies is True` и длину словаря перехватчиков.

**Почему оракул 3a-этапа не мог это поймать**: fit_panel_var — новый код этапа 3b.

запись dummy-блока + регрессионный пин на восстановление A на гетерогенной панели
