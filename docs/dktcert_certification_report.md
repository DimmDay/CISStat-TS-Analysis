## 2. Независимые оракулы — `scripts/dktcert_audit_oracle.py`, 81/81 CERT-GREEN

**[1] Контракт темы §5 — 21 проверка.** Ключ хранения ровно
`cisstat-theme` и значения `light|dark`; класс `.dark` на `<html>`;
порядок инициализации проверен ПОЗИЦИЯМИ вхождений в
`resolveInitialTheme` (localStorage → prefers-color-scheme → light);
мусор в localStorage отбрасывается строгим сравнением; персист в
`setTheme`; storage-событие с фильтром ключа. No-FOUC-скрипт:
самодостаточный IIFE; шаблонная интерполяция констант контракта
разрешена статически и сверены литералы результата (`cisstat-theme`,
`classList.toggle("dark", …)`, порядок localStorage → matchMedia).
Монтирование: блокирующий `<script dangerouslySetInnerHTML>` в `<head>`
layout, `suppressHydrationWarning` на `<html>`, обёртка
`<ThemeProvider>`; переключатель: `isDark ? Sun : Moon`, aria-метки по
состоянию, `aria-pressed`, `onClick={toggleTheme}`. §10.5:
`next-themes` отсутствует во всех package.json монорепо. §10.6:
transition-деклараций в темо-контуре нет.

**[2] Инвариант светлой темы — 13 проверок.** `:root`-тройки сверены с
НЕЗАВИСИМОЙ таблицей аудитора (канонический Tailwind v3.4 для
white/black/neutral-50…950/green/amber/red/blue/emerald/violet/sky/cyan;
светлые факты платформы для brand #2E3192, brand-light #E8EAF6,
footer-семейства, footer-bg #CAD7F7) — 66 токенов, байт-в-байт. В
`:root` нет необъяснённых токенов. Имена `--c-*` в `.dark` совпадают с
`:root` 1:1 (нет ни пропусков, ни лишних). Исключения §6.2 подтверждены:
neutral-950 (код-блок) и black не инвертируются, white-fg белый в обеих
темах. Пресет: `darkMode: "class"`, 64 ссылок на токены (≥60 занятых
шагов), формат значений строго `rgb(var(--c-*) / <alpha-value>)`
(механизм слэш-прозрачности R-1); dangling-var отсутствует — каждый
токен пресета определён и в `:root`, и в `.dark`. chart/status/wave
переменные: имена 1:1 в обеих темах; `color-scheme: light/dark` на месте.

**[3] Контраст-аудит каталога — 36 проверок (собственный WCAG-движок).**
Опорные тёмные значения сверены с каталогом §6 (page #0B0C10, карточка
#16171C, поверхность-50 #1C1D23, brand-bright #8F94F5, заливка brand
#4A4ED9, футер #171D2C). Прогнаны 26 тёмных пар: текст-1/основной/текст-1/
текст-2/вторичный на карточке, странице и поверхности-50 (≥4.5);
placeholder — AA-large (≥3.0, честная классификация); brand-bright на
карточке/странице/поверхности/brand-light (≥4.5); white-fg на заливке
brand (≥4.5); статусные тексты на своих тёмных поверхностях
(green/amber/red/blue/emerald/violet/sky, ≥4.5); футер: текст
(≥4.5) и плейсхолдер (AA-large). Факт-числа спеки подтверждены с
допуском: brand-bright/карточка ≈ 7:1 (§6.3), футер-текст ≈ 15:1
(DKT-5). Сантити светлой темы: 7 пар (neutral-900/800/500, brand,
green-700/amber-700/red-700 на своих поверхностях) — инвариант
читаемость не деградировал.

**[4] Экспорт PNG — 7 проверок.** Порядок операций в
`ForecastExportMenu.downloadChartPng` по позициям: cloneNode →
`resolveSvgVarsLight(clone)` → XMLSerializer → canvas →
`fillStyle = "#FFFFFF"` → drawImage — резолв строго ДО сериализации
(§6.4), заливка строго ДО отрисовки (§10.1 «всегда светлый»).
`CHART_VARS_LIGHT` — точное зеркало СВЕТЛОГО `:root` по всем 52
переменным chart/status/wave (значение-в-значение; тёмный блок для
сверки не использовался — источник карты по спецификации только `:root`).
`RESOLVED_ATTRS` покрывает fill/stroke/stop-color + style-ветку; резолв
работает на клоне (исходный SVG не мутируется); вне карты var()
остаётся видимым (fail-visible, не молча-чёрный).

**[5] Guard-нетронутость светлой вёрстки — 4 проверки.** Инвентарь
`dark:`-оверрайдов в компонентах/оболочках: ровно 2 файла —
документированные исключения §6.2 (`ModelingWorkflowOverview.tsx` —
Model Card JSON-блок; `TsAnalysisModeling.tsx` — шеврон). `.dark`-селекторы
живут только в `globals.css` (никаких рассеянных ревизий). DKT-коммиты
(`e99cd1f`, `1afb10b`, `6dacd2c`) не трогают `apps/api/` и `tests/` —
бэкенд серии 0-дифф (заявка DKT-5 подтверждена на уровне git). Пресет
не вводит новых имён классов — только значения var (контрольный факт
Варианта C: guard-тесты строк классов остаются валидными без правок).
