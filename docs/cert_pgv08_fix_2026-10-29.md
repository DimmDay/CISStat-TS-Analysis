### Реальные runtime-пробы: что именно проверено

HTTP использует compiled production server и smoke --serve, реальный playwright-core
1.57.0 и собственный slow shell executable вместо Chromium. Проверены 503
missing_browser, 422 oversized scale, 503 render_timeout примерно за 1s, запись PID
реально начавшегося процесса, его отсутствие через kill(pid,0), дальнейший healthz.
Это не PNG browser E2E, не kernel sandbox и не финальный image smoke.

Собственный SSR oracle запускает actual compiled worker thread общего PGV-07
бандла, проверяет кириллицу и отмену тяжёлой таблицы без блокировки event loop.
Картинка или OCR этим не удостоверяются.
