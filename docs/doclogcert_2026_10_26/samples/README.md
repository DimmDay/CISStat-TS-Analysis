# Образцы документов из текущего продукта

Получены в изолированном воспроизведении реального пути на f1d6151, а затем **явным** созданием через API. Научные результаты и callbacks для promotion не подменялись заранее созданными артефактами.

- D02/D03/D04 в PDF, MD, HTML, JSON — точные rendition-ответы продукта.
- `D02.snapshot.json` и аналогичные — frozen-источники рендера.
- `progress_history.md` — штатный MD-отчёт «Прогресса» того же run.
- `forecast_monitor_synthetic_n150.csv` — вход из штатного TS-генератора.

Это **ограниченные несогласованные черновики**: `data_ref=null`, `reproducibility=limited`, нет переноса паспорта/данных в artifact layer. Ошибочные `complete`/`current` оставлены без изменения как доказательства аудита. Детали — в `../certification.md` и `../scenario_commentary.md`.

PDF проверены рендерингом и визуально; это проверка читаемости, не содержательная сертификация полноты. Файлы содержат только собственные синтетические данные/ID опыта и не являются документами пользовательской production-сессии.
