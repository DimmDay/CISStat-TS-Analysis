## 5. Находки (Класс B — RED-свидетельства)

**F-P1C1 (средняя; паритет/робастность зеркала).** `apps/api/print_schema.py` на non-finite числах расходится с TS-каналом: `print.page_count=Infinity` → **OverflowError** (крэш валидатора; TS честно возвращает `missing_field`); `annotations.revision=NaN` → **ValueError** (TS: `missing_field`); `sampling.point_cap=NaN` **молча принимается** (TS: `missing_point_cap`); `heatmap_scale.domain=[Infinity,1]` **принимается** (TS: `missing_heatmap_scale`). Reachability честная: стандартный `json.loads` Python принимает литералы `Infinity`/`NaN`, а зеркало — заявленный preflight для PGV-02/09: крэш = 500 вместо 422, приём = нечестная печать. Корень: `_num` без аналога `Number.isFinite` и негардящие `int()`-конверсии.

**F-P1C2 (средняя/низкая; паритет контракта кодов).** Семантика непрерывности порядка страниц: TS (`forEach`) считает **каждый** несовпавший индекс, Python останавливается после первого (`break`) и **исключает невалидные страницы из базлайна сравнения** — на одинаковых payload'ах мультимножества `(code, path)` различны: `[1,2,4,5]` → TS 2 / PY 1; `[0,1]` → TS 3 / PY 1; `[1,1,2]` → TS 3 / PY 2 (F2a/F2b/F2c). UI-валидация (TS) и preflight (PY) докладывают разное число нарушений одного payload — контракт «те же правила» нарушен на уровне счётчиков.

**F-P1C3 (низкая; документация, класс F-P0C1).** Устаревшие пины «89» в артефактах PGV-01 после PGV-00-FIX (denominator 93): комментарий в источнике истины `printSchema.ts` («используется оракулом реестр⇄схема, все 89 сайтов») и шапка doc-гварда `check_documents.py` («89 sites»). Код обоих файлов корректен (93) — дрейфят именно комментарии, вводя в заблуждение читателя акта/кода.

Наблюдения (неблокирующие): N1 — манифест с 0 страниц валиден в обоих каналах (минимум страниц не запиннен; `page_count≥1` закреплён только в снапшоте); N2 — `page_role`/`dependencies` манифеста не валидируются по содержимому; N3 — site-less режим валидатора слабее (sampling default true, allowlist не сверяется с реестром) — осознанный дизайн, требует документации в PGV-02/09; N4 — repo-тест `test_reused_checkpoint_needs_confirmation` передаёт посторонний kwarg `times_overridden=True` (безвредный мусорный ключ фиксатора).

## 7. План PGV-01-FIX (кандидат)

1. **F-P1C1:** Python-зеркало — конечность чисел (`_num` → аналог `Number.isFinite`; гард `int()`-конверсий): non-finite → честные коды (`missing_field` / `missing_point_cap` / `missing_heatmap_scale`) в обоих каналах; Класс B обязан стать GREEN без правки смысла.
2. **F-P1C2:** канонизировать семантику непрерывности (рекомендация: forEach-семантика TS — считать каждый несовпавший индекс, невалидные страницы включать в базлайн) и синхронизировать Python-зеркало; альтернатива — решение тимлида с фиксацией в спеке и синхронной правкой обоих каналов.
3. **F-P1C3:** правка двух комментариев 89→93.
4. Опционально: пин минимума страниц манифеста и валидация `page_role`/`dependencies`; документация site-less режима; чистка kwarg N4.
