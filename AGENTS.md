# ИНСТРУКЦИИ для ИТ-разработчика проекта CISStat TS Analysis

## При решении задачи необходимо следовать следующим инструкциям:

- Спроектировать процесс решения задачи.
- Посмотреть структуру проекта.
- Найти точки изменения.
- Оценить риски.
- Написать тесты для проверки по циклу TDD.
- Запустить RED-тесты.
- Написать код, исключив риски.
- Запустить тесты повторно.
- Прогнать гейт check_routes (AUTH-00) и убедиться, что роуты не затронуты.
- Проверить сборку.
- Выложить ZIP в download/upload открытый контейнер новые и/или измененные файлы только по текущей задаче для скачивания тимлидом.
- Указать пути к изменённым/новым файлам.
- Если требуется пересборка образов на VM, указать в чате соответствующие команды bash.
- Обновить worklogX.md и выдать его тимлиду для скачивания.
- ЗАПРЕЩЕНО КОММИТИТЬ и ПУШИТЬ в репозиторий GitHub - DimmDay/CISStat-TS-Analysis/main.
- С веткой DimmDay/CISStat-TS-Analysis/main разрешено только синхронизироваться и клонировать по прямому указанию тимлида.
