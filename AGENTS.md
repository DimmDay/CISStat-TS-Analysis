# ИНСТРУКЦИИ для ИТ-разработчика проекта CISStat TS Analysis

## При решении задачи программирования нового кода или создания патча, необходимо следовать следующим инструкциям:

- Спроектировать процесс решения задачи
- Посмотреть структуру проекта
- Найти точки изменения
- Оценить риски
- Написать тесты для проверки
- Написать код, исключив риски
- Проверить сборку
- Выложить в download только новые и/или измененные файлы.
