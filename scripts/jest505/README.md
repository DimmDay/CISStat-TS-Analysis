# JEST-505 — план и воспроизведение

База: `505c304582e3dbd39b5b5bc03de2cbb8011d31f3`, изолированное detached worktree.

1. Установить зависимости корня через `npm ci --ignore-scripts --no-audit --no-fund`.
   `playwright-core@1.57.0` уже объявлен workspace и lock-файлом; глобальная
   установка или типовая заглушка не заменяют эту зависимость.
2. Запустить пять указанных suite, сохранить RED и фактические исключения.
3. Проверить журнал PGV-07 против исполняемого doc-contract guard.
4. Проверить cancellation до spawn и EDA смену цели, включая асинхронные
   границы React и задержанные ответы. Не снимать проверки отсутствия exec,
   сброса просмотров и новой доставки; не увеличивать таймауты ради GREEN.
5. Повторить адресный срез, полный Jest без исключений, renderer build и
   typecheck обоих приложений. Проверить production builds отдельно.
6. Записать реальные результаты и границы в worklog11; архивировать только
   изменения этой задачи и протоколы. Без commit/push.

Риски: ложный GREEN при отсутствующей runtime dependency; случайный POSIX
исполняемый файл хоста вместо shell-контракта контейнера; гонка ожидания
React state; изменение исторических свидетельств; запуск полного теста
одновременно с мутациями. Исторические RED-протоколы не переписываются.

Команды (из корня репозитория):

```sh
npm ci --ignore-scripts --no-audit --no-fund
npx jest --maxWorkers=2
npm run build --workspace=@cisstat/print-renderer
npm run typecheck:all
npm run build:all
```

В контейнере с отсутствующим `/tmp` задайте `TMPDIR` на существующий
доступный каталог. Это настройка среды, а не обход тестовых проверок.
