## 5. Находки сертификации

**F-1 (Low, защитный контур движка, НЕ блокирует).**
`select_case_bank_candidates` принимает `mape=NaN` как доказательство скора:
`float("nan") > max_backtest_mape` — всегда False → NaN-запуск проходит порог
(O6.12), попадает в кандидатов с `backtest_mape=NaN` и делает сортировку
нестабильной. Достижимость: **в проде невозможна** — HTTP-путь отсекает NaN
(Starlette JSONResponse: `allow_nan=False`), Postgres JSONB NaN не хранит.
Риск возникает для БУДУЩИХ офлайн-потребителей §9, скармливающих движку
произвольные экспорты (numpy-инструменты пишут NaN в JSON по умолчанию).
Рекомендация: `math.isfinite(mape)` рядом с `float(raw_mape)` — дух «no
fabricated results» (NaN — не скор). Однострочная правка, может войти в любую
следующую PROGR-задачу.

**R-1 (Info):** без заголовка X-API-Key админ-эндпоинты отвечают 422
(валидация `Header(...)` FastAPI), а не 401 — панель трактует как общую
недоступность («Сервис недоступен»), не как «неверный ключ». Косметика UX,
контракт не нарушен (O9.4 фиксирует фактическое поведение).

**R-2 (Info):** `runs_by_status` для прямых dict-входов движка с не-каноническим
статусом добавит лишний ключ (ResearchRun валидирует статусы — через слой 2
невозможно; канонические 4 ключа присутствуют всегда). Честная деградация.

**R-3 (Info):** `CaseBankResponse.criteria` (Dict[str, float]) отдаёт целые
пороги как 2.0/2.0; панель criteria не рендерит — эхо для прозрачности. Нит.
